# Хранение данных в IndexedDB через Dexie

Приложение локальное: данные живут на устройстве, без сервера и аккаунта. Они
хранятся в IndexedDB через Dexie, как в tallystick. Компоненты читают их живыми
запросами (`useLiveQuery`), без копии в отдельном сторе. Объём мал — десятки
помидоров в день, — поэтому подсчёты по периодам выполняются на TypeScript по
данным в памяти.

Схема меняется только новой версией `db.version(n)` в `src/db.ts`; данные старой
схемы переводятся в её `upgrade`. Уже выпущенные версии не правятся: браузер
пользователя применил их и повторно не запустит.

## Рассмотренные варианты

- **SQLite в браузере** (sqlite-wasm в OPFS). Требует воркера и SQL-слоя, а
  сложных запросов при таком объёме нет.

## Последствия

- Без разрешения на постоянное хранение браузер может удалить данные при нехватке
  места, поэтому приложение запрашивает его при запуске; на iPhone данные надёжно
  живут только у приложения, установленного на экран «Домой».
